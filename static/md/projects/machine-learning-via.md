# Machine Learning Projects from VIA University

These were part of the Introduction to Machine Learning course at VIA College University

### Digits
The Digist project is about regocnizing hand-written digits using clustering algorithms
* [Project 3: Handwritten Digits (Clustering)](/mal/project-3-digits)

### Sentiment Analysis
The Sentiment Analysis project is about using a Neural Network to analyse the sentiment of comments and predicting if the comment was negative or positive.
* [Project 5: Sentiment Analysis (Neural Network)](/mal/project-5-sentiment-analysis)

### Speech Recognition
The Speech Recognition project is about using a Convolutional Neural Network on voice recordings of "yes", "no", "stop" and "go", to try and predict which ones are said.
* [Project 6: Speech Recognition (Convolutional Neural Network)](/mal/project-6-speech-recognition)

### World Happiness
The World Happiness project was the final project where we had to find our own data and analyse it as we saw fit. For this we analysed correlations between world happiness and alcohol consumption.
* [Project 7: World Happiness (Regression)](/mal/project-7-happiness)
